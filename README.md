# 🎮 Эволюция Слаймов: Слияние и Кликер (Yandex Games Ready)

Готовая игра жанра **Merge / Clicker / Evolution** для публикации на платформе **Яндекс Игры** с полной интеграцией **Yandex Games SDK v2**.

---

## 🌟 Особенности игры

1. **Геймплей:**
   - **Инкубатор:** созревание яиц слаймов по таймеру + ускорение кликами со сбором монет.
   - **Слияние (Merge):** перетаскивание одинаковых слаймов друг на друга для эволюции в новый уровень (всего **20 уникальных уровней**).
   - **Пассивная прибыль:** каждый слайм на поле 4x4 генерирует пассивный доход каждую секунду.
   - **Оффлайн-доход:** игра подсчитывает время отсутствия игрока и выдаёт накопленные монеты при возвращении (с возможностью удвоить за просмотр рекламы).
   - **Магическая прокачка (5 веток):** скорость инкубатора, сила клика, общий множитель дохода, качество яиц, авто-слияние.
   - **Книга питомцев (Коллекция):** просмотр всех 20 видов слаймов и их характеристик.
   - **Задания и достижения:** система наград за прогресс.

2. **Интеграция с Яндекс Игры SDK:**
   - `YaGames.init()` с вызовом `ysdk.features.LoadingAPI.ready()`.
   - **Межстраничная реклама (Interstitial):** `ysdk.adv.showFullscreenAdv` при открытии новых видов слаймов (с умным кулдауном в 60 секунд для соблюдения правил модерации).
   - **Реклама с вознаграждением (Rewarded Video):**
     - Буст дохода x2 на 2 минуты.
     - Моментальный сундук с монетами (+15 минут дохода).
     - Удвоение оффлайн-прибыли при входе.
   - **Облачные сохранения:** `ysdk.getPlayer().setData()` / `getData()` с автоматическим резервным сохранением в `localStorage`.
   - **Таблица лидеров:** передача максимального уровня слайма в `highest_tier`.
   - **Запрос оценки (Review prompt):** автоматический вызов предложения оценить игру при достижении 7 уровня слайма.
   - **Mock-режим:** если игра запущена локально без интернета или SDK Яндекса, игра не падает, а симулирует рекламу и сохранение.

3. **Технические преимущества:**
   - **0 сторонних библиотек и тяжелых ассетов:** все звуки генерируются процедурно через Web Audio API, а графика рисуется на Canvas.
   - Вес архива — всего **~34 КБ**! Загружается мгновенно на любом мобильном устройстве и слабом интернете.
   - Адаптивный дизайн под смартфоны (сенсорный ввод touch drag&drop) и компьютеры (мышь).

## 🚀 Как протестировать локально прямо сейчас

1. Откройте файл `index.html` в любом современном браузере (Chrome, Яндекс Браузер, Edge, Firefox).
2. Игра автоматически запустится в локальном режиме:
   - Кликайте по яйцу для ускорения.
   - Перетаскивайте одинаковых слаймов друг на друга для слияния.
   - Покупайте улучшения во вкладке «Прокачка».
   - Тестируйте кнопки с рекламой (появится подтверждение симуляции просмотра).

## 📤 Инструкция по публикации в Яндекс Игры

### Шаг 1. Перейдите в Консоль разработчика
1. Откройте [Консоль разработчика Яндекс Игр](https://yandex.ru/dev/games/console/).
2. Авторизуйтесь под своим Яндекс-аккаунтом.
3. Нажмите кнопку **«Добавить приложение»**.

### Шаг 2. Загрузка исходного кода
1. В разделе **«Исходный код»** выберите тип **«Файл»**.
2. Загрузите готовый файл **`game.zip`** (он находится в корне этой папки).
   > *Важно: архив уже сформирован строго по правилам Яндекса — `index.html` лежит в корне архива.*

### Шаг 3. Заполнение информации об игре
- **Название:** `Эволюция Слаймов: Слияние и Кликер`
- **Категория:** `Казуальные`, `Аркады` или `Кликеры`
- **Возрастной рейтинг:** `0+`
- **Ориентация:** `Портретная` (или `Любая`)
- **Иконка:** Загрузите файл **`icon.png`** (512x512 уже готов в папке).
- **Описание:**
  > Скрещивайте милых слаймов, открывайте редкие виды и постройте самую богатую слайм-империю!
  > 
  > Особенности:
  > • 20 уровней уникальных забавных существ!
  > • Улучшения инкубатора и автослияние!
  > • Пассивный доход даже когда вы не в игре!

### Шаг 4. Настройка таблицы лидеров (по желанию)
1. В разделе **«Таблицы лидеров»** нажмите «Создать».
2. Техническое имя: `highest_tier`
3. Название: `Максимальный уровень`
4. Формат: Числовой (по убыванию).

### Шаг 5. Проверка в черновике и отправка на модерацию
1. Нажмите **«Сохранить»** и откройте **«Черновик»** в окне предпросмотра.
2. Убедитесь, что игра запускается, реклама открывается в тестовом режиме Яндекса.
3. Нажмите **«Отправить на модерацию»**! Модерация обычно занимает от нескольких часов до пары дней.

```powershell

```
Файл `game.zip` будет мгновенно обновлен.
